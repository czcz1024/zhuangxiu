# 2026-07-25 工作日志

## 家具摆放工具：新增"自定义房间"功能
- 在工具栏"导入户型图"旁新增"自定义房间"按钮
- 功能：不导入户型图，直接输入房间宽度(mm)和深度(mm)，自动生成房间平面
- 自动设置比例尺(pixelsPerMm)，无需手动校准
- 房间渲染：浅灰背景 + 500mm网格线 + 深色边框 + 尺寸标注(宽度标上方、深度标左侧旋转)
- 支持编辑房间尺寸：已有家具和测量点按物理位置(mm)等比保留
- 修改了所有依赖 bgImage 的判断逻辑，改为 (bgImage || room) 兼容两种模式
- 存档系统(version 3)新增 room 字段，支持自动保存/导出/导入
- 导入户型图时会自动清除 room，两种模式互斥

## 家具摆放工具：新增"门窗"功能（自定义房间模式）
- 工具栏新增"添加门窗"按钮，弹出模态框可选门/窗
- 门参数：墙面(上/下/左/右)、铰链位置(mm)、门宽(mm)、内开/外开、铰链侧(正向/反向)
- 门渲染：门洞(覆盖墙线) + 半透明扇形开门扫过面积 + 门板线(打开90度状态) + 铰链点 + "门"标签
- 窗渲染：窗洞 + 双线窗框 + 玻璃中线 + "窗"标签
- 扇形绘制核心：计算门板方向(startAng)和开门方向(endAng)的角度差，判断顺/逆时针绘制90度弧
- 门窗可点击选中(独立侧边栏openingPanel)，支持实时编辑墙面/位置/宽度/颜色/开门方向
- Delete键和工具栏删除按钮均支持删除门窗
- 存档系统支持openings数据(自动保存/导出/导入)
- 门窗仅在room模式下可用(无房间无墙)

## 家具摆放工具：门窗支持拖拽移动和调整大小
- 新增 dragOpening 变量和辅助函数(distPoint/openingEndpointsPx/wallPosMm/wallLenMm/clampWallPos/dragUpdateOpening/syncOpeningInputs/renderOpeningHandles)
- 选中门窗后两端显示白色圆形手柄，拖动手柄调整宽度(最小100mm)
- 拖动门窗本体沿墙移动(仅1D沿墙方向，自动吸附在墙面上，超出墙长自动夹紧)
- 门拖大宽度时扇形开门面积同步增大(扇形半径=门宽)
- 拖远端越过铰链时自动翻转铰链侧(side)，扇形朝向跟随翻转
- 光标反馈：手柄上显示ew-resize/ns-resize，选中本体显示move，未选中显示pointer
- 拖拽时侧边栏数值实时同步(不重建HTML避免闪烁)
- 存档/加载不受影响(门窗数据结构未变，仅交互方式改变)
