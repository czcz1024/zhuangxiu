# 旧房翻新项目 — 长期记录

## 项目概况
- **房屋类型**: 旧房整体翻新，20年以上老小区
- **所在城市**: 山西太原，5层楼住3层
- **气候特点**: 北方干燥寒冷，冬季需供暖保温
- **当前阶段**: 规划阶段，尚未开始
- **翻新动机**: 接入集中供热 → 铺地暖需要刨地 → 顺势全屋翻新

## 家庭成员（核心设计依据）
- **母亲**: 70多岁，身体状况尚可，需考虑未来行动不便 → **适老化设计**
- **用户与妻子**: 40多岁
- **儿子**: 高一（约16岁）→ **学习环境优先**
- **总居住人数**: 3代4口人

## 约束条件
| 条件 | 说明 |
|------|------|
| 结构 | 尽量不砸墙，保持原有格局 |
| 家具家电 | 老家具+冰箱/电视/洗衣机保留沿用 |
| 生活习惯 | 装修后格局和生活动线尽量不变 |
| 面积 | 待实测 |
| 预算 | 12万左右（硬装），优先保证隐蔽工程和不能后期升级的项目 |

## 装修期间安排
- 在外面租房解决居住问题

## 设计核心原则
1. **适老化**: 地面防滑、无高差、卫生间预留扶手位、通道宽度考虑轮椅
2. **学习环境**: 隔音、充足照明、独立书桌区、网络布线
3. **结构安全**: 不砸墙、开槽注意深度
4. **预算控制**: 12万，重点投入隐蔽工程（窗户/防水/电线/墙面基层）

## 核心决策（已定）
- 供暖方案：地暖（集中供热）
- 地暖分水器位置：餐厅（非厨房）→ 厨房吊顶不需留分水器检修口，餐厅吊顶/检修口需在分水器正上方预留
- 水电：全屋重做
- 水浸传感器：厨房水槽柜下+卫生间各装1个（50-80元/个，漏水自动报警，保护地暖层和地板）
- 厨房水槽：**单槽**（材质待定：不锈钢/石英花岗岩复合材料）
- 厨房照明：**一个最简单的吸顶灯**（不要灯带不要轨道灯）
- 厨房墙面：**瓷砖**
- 厨房地漏：**保留现有地漏**
- 净水器：**装**（水槽柜下，需预留电源+下水）
- 小厨宝：**装**（水槽柜下即热式热水器，功率1500-2000W，**必须单独一路线**，不能和净水器/冰箱混用）
- 沿用不换的物品（拆旧时需保护）：
  - 吸顶灯（2026元旦刚换新，圆形简约款）
  - 马桶（现有正常，法兰圈建议换新防臭，马桶旁预留防水插座供未来智能盖升级）
  - 窗户（20年老窗，保温差但省预算；建议换密封条+发泡胶填缝+厚窗帘等低成本补救）
  - 老家具、冰箱、电视、洗衣机

## 橱柜方案（统一颗粒板，已定）
- **全柜柜体**：颗粒板（爱格/可丽芙级别品牌板，非杂牌）— 用户综合考量预算与现今板材工艺进步（PUR封边+防水芯材大幅降低发霉概率）后决定，不另做水槽柜不锈钢
- **台面**：石英石（≥15mm、石英砂≥90%、压制成型、纯色或细颗粒花色接缝最不明显）
- **选购盯死**：品牌颗粒板（爱格/可丽芙级别，拒杂牌薄板）、PUR封边（拒EVA）、品牌五金（海蒂诗/百隆/DTC）
- **防潮加强**：水槽柜+洗碗机柜底板做铝箔包底处理、水槽柜背板贴防潮膜、所有截面严密封边
- 背景：原方案分区域（水槽柜不锈钢+地柜多层板+吊柜颗粒板），后因用户认为现今板材工艺进步、发霉概率大降，改为统一颗粒板省预算；水浸传感器仍作为漏水预警兜底

## 厨房特殊条件
- **灶台和洗菜池面对面分开**（不在同一排），高低台各做各的高度，无过渡问题
- **烟机直排窗外**（无公共烟道）→ 风压需求极低，普通≥18m³/min即可，止逆阀防冷风倒灌
- 装修时统一墙洞为160/180mm标准口径+止逆阀+防雨帽，方便以后换烟机

## 核心决策（已定）
- 厨房门轨道：**超薄地轨**（凸出地面≤8mm）。否决吊轨（重门长期受重下垂变形+密封差油烟外溢）、否决传统地轨（3-5cm高差绊脚藏油污不适老）。选购要点：铝合金实心厚壁轨道、尼龙密封轴承滑轮、5mm钢化玻璃门扇（别太重）、轨槽每周吸尘。施工时机：铺地暖刨地阶段把轨道嵌入地砖找平做到齐平，利用刨地红利
- 厨房吊顶：**铝扣板**（轻钢龙骨、板厚≥0.5mm、哑光纯色白/浅灰、300×600规格）。否决蜂窝大板（贵2-3倍）、防水石膏板（油污发黄+检修灾难）、PVC扣板（老化发黄）、生态木（油污难清）。工艺：轻钢龙骨防锈不用木龙骨、检修空间≥15cm、排风墙洞吊顶前先打好走吊顶内。分水器在餐厅，厨房吊顶不留检修口
- 灶具+台面：**嵌入式灶 + 石英石台面**（绑定决策）。石英石整板开洞承重稳、耐高温不变形，是嵌入式灶标准搭档；台式灶+不锈钢台面路线否决（不锈钢薄板开大洞边缘变形风险）。选购：石英石≥15mm、石英砂≥90%、压制成型、纯色或细颗粒花色接缝最不明显；注意热锅必须垫隔热垫防骤热炸裂

## 核心决策（待定）

- 橱柜门板：饰面工艺待定（PVD镀钛聊过未确认；双饰面/PET/烤漆等可选）
- 水槽材质：不锈钢 vs 石英花岗岩复合材料
- 装修方式：全包 / 半包 / 清包
- 面积：待实测
- 风格方向：待确定
