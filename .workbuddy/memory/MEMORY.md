# 旧房翻新项目 — 长期记录

## 项目概况
- **房屋类型**: 旧房整体翻新，20年以上老小区
- **所在城市**: 山西太原，5层楼住3层
- **气候特点**: 北方干燥寒冷，冬季需供暖保温
- **当前阶段**: 规划阶段，尚未开始
- **翻新动机**: 接入集中供热 → 铺地暖需要刨地 → 顺势全屋翻新

## 家庭成员（核心设计依据）
- **母亲**: 70多岁，身体状况尚可，需考虑未来行动不便 → **适老化设计**
- **用户与妻子**: 40多岁
- **儿子**: 高一（约16岁）→ **学习环境优先**
- **总居住人数**: 3代4口人

## 约束条件
| 条件 | 说明 |
|------|------|
| 结构 | 尽量不砸墙，保持原有格局 |
| 家具家电 | 老家具+冰箱/电视/洗衣机保留沿用 |
| 生活习惯 | 装修后格局和生活动线尽量不变 |
| 面积 | 待实测 |
| 预算 | 12万左右（硬装），优先保证隐蔽工程和不能后期升级的项目 |

## 装修期间安排
- 在外面租房解决居住问题

## 设计核心原则
1. **适老化**: 地面防滑、无高差、卫生间预留扶手位、通道宽度考虑轮椅
2. **学习环境**: 隔音、充足照明、独立书桌区、网络布线
3. **结构安全**: 不砸墙、开槽注意深度
4. **预算控制**: 12万，重点投入隐蔽工程（窗户/防水/电线/墙面基层）

## 核心决策（已定）
- 供暖方案：地暖（集中供热）
- 水电：全屋重做
- 橱柜：不锈钢橱柜（304食品级，现有木板橱柜受潮发霉需彻底更换）
- 洗碗机：安装嵌入式洗碗机（需提前预留水电）
- 水浸传感器：厨房水槽柜下+卫生间各装1个（50-80元/个，漏水自动报警，保护地暖层和地板）
- 沿用不换的物品（拆旧时需保护）：
  - 吸顶灯（2026元旦刚换新，圆形简约款）
  - 马桶（现有正常，法兰圈建议换新防臭，马桶旁预留防水插座供未来智能盖升级）
  - 窗户（20年老窗，保温差但省预算；建议换密封条+发泡胶填缝+厚窗帘等低成本补救）
  - 老家具、冰箱、电视、洗衣机

## 厨房特殊条件
- **灶台和洗菜池面对面分开**（不在同一排），高低台各做各的高度，无过渡问题
- **烟机直排窗外**（无公共烟道）→ 风压需求极低，普通≥18m³/min即可，止逆阀防冷风倒灌
- 装修时统一墙洞为160/180mm标准口径+止逆阀+防雨帽，方便以后换烟机

## 核心决策（已定）
- 灶具：从嵌入式改为台式（非嵌入），不锈钢台面不开大洞只钻走管小孔，以后换灶零约束

## 核心决策（待定）

- 面积：待实测
