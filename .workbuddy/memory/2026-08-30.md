- 新增"水电点位"工具栏：18 种预设点位（五孔插座/开关/双控/网口/电视口/空调/床头/书桌/电视挂墙/厨房台面/油烟机/水槽柜下/冰箱/洗衣机/热水器/智能马桶/弱电箱/配电箱），各带默认高度

- 新增"点位清单"导出：表格弹窗 + CSV 下载 + 打印/存PDF
- 新增"高度参考"弹窗：常见点位标准高度速查表
- 点位数据并入 autosave/导出存档（version 4）

## 立面视图（第二波）
用户需要"看到那面墙"检查家具高度/遮挡 → 加了立面视图模式：
- 工具栏"立面视图"按钮 → 全屏 overlay，独立 canvas
- 墙面管理：从自定义房间生成四面墙（左/上/右/下，长度自动）/ 手动新增 / 改墙长 / 右键重命名 / 删除，层高可调(默认2800)
- 侧视家具预设18种（沙发/电视柜/挂墙电视/床/衣柜/冰箱/油烟机/吊柜/空调挂机/门/窗等，带真实宽高，挂墙类默认底部离地）
- 点位与平面同款18种，点击高度即放置高度；点选拖动、右侧面板精调 x/高度
- 自动遮挡检测：点位落在家具矩形内 → 红圈+"被遮挡"标注；"遮挡检查"按钮出汇总
- 导出：CSV/打印/点位清单弹窗均含立面点位（墙名+距墙左端mm+高度）
- 存档 version 5；打开立面时清空平面选中防误删

## 平面↔立面联动（第三波）
用户痛点：平面标好插座/网口/电视口后，想看某一面墙立面核对高度和家具遮挡，但原先两套数据不联动。
存档升到 version 6：
- 平面入口：工具栏「左/上/右/下墙立面」四按钮 + 房间四边外「点此看立面」标签，一点即开该墙
- 点位自动吸附最近墙，侧栏可改所在墙/距立面左端；立面改高度或左右位置会写回平面
- 立面自动投影：该墙门窗、靠墙≤220mm 的家具（按名称推断高度，侧栏可改高度/底部距地）、贴墙点位
- 遮挡检查覆盖平面贴墙点位；门窗洞内也会提示
- 「同步四面墙」不再清空已有立面手摆内容；联动墙长跟房间走
