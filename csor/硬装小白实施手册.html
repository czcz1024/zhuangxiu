0先把你家的硬条件钉死

装修公司最爱用「别的家都这么干」糊弄你。你家不是普通精装房，有四件事情会改掉很多常规做法。后面每一章都按这四条来，不要让工人按「默认做法」施工。

你家和普通装修不一样的四件事
条件意味着什么工人常想怎么偷
太原老楼，冬天可到 -20℃ 地暖保温板要 3cm；阴面阳台厨房必须防冻 保温板用 2cm 或泡沫板；水管走外墙
现在单位锅炉暖气片，以后可能接大暖 立管不能割断；楼道预留供回水口；房内混水 + 切换阀 高温水直灌地暖；拆立管；不留接口
厨房在阴面阳台，只有 1 个卫生间 厨房按卫生间同等防水；厨房必须做地暖 阳台只简单贴砖、不做防水和地暖
全屋地砖 + 家里有 70 多岁老人 客卧柔光砖，厨卫防滑砖，尽量无高差 推亮面砖；厨卫做门槛高差；水泥砂浆贴大砖
一句话总原则
面层可以选中档，管子、电线、防水、地暖不能省。有地暖的房间，给水管和电线一律不走地面。

硬装预算大约 12 万时：瓷砖选东鹏/马可波罗/诺贝尔中端就够；地暖管、PPR、电线、防水涂料必须写进合同的品牌和型号，材料进场你本人核对喷码和检测报告。

客厅 / 卧室
地暖 + 柔光地砖。水电竖槽走墙，地面不走管。
厨房 / 卫生间
横干走铝扣板吊顶，竖分走墙。槽内先刷防水再埋管。
全屋地面
只铺地暖盘管，不走给水、不走电线。走地等于焊死，坏了要砸地。
怎么判断材料优不优质（比认牌子更重要）
  • 第一看参数：管径、壁厚、线径、密度、压缩强度——数字骗不了人
  • 第二看认证：国标编号、CCC、卫生许可、型式检验报告（CMA/CNAS）
  • 第三看品牌：大品牌底线有保障，但同品牌也分档次，只认牌子不查型号等于没查

下文品牌都写成「首选 / 可接受备选 / 直接拒绝」，不是唯一真理。太原能买到、参数达标即可。

面层可以选中档，管子、电线、防水、地暖不能省。隐蔽工程出问题 = 砸地砸墙，维修费是当初施工费的十倍起。

1拆除刨地

旧房要全部拆掉、刨地刨墙、水电全换。这一步看起来「砸就完了」，但老楼最容易伤结构、伤楼下、把不该拆的立管拆了。

选什么

这一步几乎不买主材

要准备的是保护：楼下打招呼、楼道铺彩条布、门口挡板。窗户这次不换（已定），拆墙时用木板/薄膜挡住窗框，别砸裂玻璃和密封条。

怎么做

刨到楼板，停

  • 原地砖/找平层刨掉，露出结构楼板即可，不能往下凿伤预制板/现浇板
  • 暖气片可以拆，穿楼板的竖直供回水立管不能割断
  • 尽量不砸承重墙（已定：保持原格局）
  • 厨房阳台原有地漏先保护，能留则留
等几天 / 贴膜

刨完清干净就能往下干

不用晾。但水电开槽前地面要扫净、浇水湿润找平用。窗户、保留的马桶（如暂不拆）、吸顶灯拆下收好，不要扔。

你怎么验收

看三件事

  • 楼板露出来了，没有被凿出坑、露出钢筋乱砸
  • 立管还在，用保温棉临时包上，阀门没被拆丢
  • 楼下天花板没有新裂缝、没有漏渣（当天就下楼看一眼）
拆除这一步直接喊停的情况
  • 工人说「立管碍事，先割掉以后再接」——楼上楼下可能还靠这根管子过水
  • 承重墙上开很长的横槽或把门洞乱扩
  • 把垃圾从窗口往下倒

2地暖双热源：单位锅炉 + 预留大暖

这是你家最特殊、也最容易被装错的一块。单位锅炉和以后市政二次网的水，温度大概 50–70℃；地暖只要 35–45℃。高温水直接灌进地暖管，地面会烫、胶会空鼓、管子寿命会短。必须加混水。两套热源还不能同时开。

推荐接法（现在就能装，大暖来了只接楼道那两根管）
立管保留 → 阀门 A 接现在的单位锅炉；楼道预留口 → 阀门 B 接未来大暖；两路汇到过滤器 + 混水中心，再进餐厅的铜分水器。

户内板式换热器先留位置、先留接口，现在不必买。等热力公司进场，如果要求隔离开式连接，再加小型板换。

双热源只在混水中心之前切换。混水之后永远是低温水进分水器，地暖盘管看不到「锅炉水」还是「大暖水」。

选什么（写进合同）

混水中心 必配
循环泵 + 恒温混水阀 + 过滤器 + 温度表 + 压力表。首选曼瑞德、丹佛斯；可接受备选：意瓦、金牛。拒绝：只有分水器、没有混水和泵，把立管高温水直接接进去。
铜分水器 餐厅已定位置
H59-1 黄铜、整体锻造（不是拼接焊管）、壁厚 ≥2.6mm、公称压力 ≥1.0MPa。首选曼瑞德、丹佛斯、意瓦。约 100㎡ 做 5–7 路：客厅、主卧、次卧/儿子房、厨房阳台、卫生间。底部距完成地面 ≥300mm。正上方吊顶留 ≥30×30cm 检修口。配电箱也在餐厅，两者间距 ≥30cm。
切换阀与楼道预留
阀门 A、B 用全通径铜球阀 + 止回阀，或一把三通切换阀互锁。楼道预留供 + 回两根，建议 De25（PPR S2.5 或热力公司指定材质），出墙加阀门和堵头，套 9mm 以上橡塑保温棉。打楼道墙前先问物业。大暖没来之前阀门常关，堵头拧紧。

怎么做

  1. 先量清立管位置，在本户用三通接管，立管上下贯通保持原样，包保温。
  2. 从室内向楼道打孔预埋供回水，内侧加阀门 B 和堵头，外侧暂时封死。孔洞发泡胶填实，外侧做防水收口，避免楼道冷风灌进来。
  3. 混水中心和分水器装在餐厅同一检修区，先装支架调水平，再接管。过滤器装在混水之前，以后能拆下来清洗。
  4. 每路地暖管从分水器出去再回到分水器，一根到底，中间不许接头。
  5. 阀门上贴标签：「A 单位锅炉（现在用）」「B 市政大暖（预留，常关）」。再写一行：禁止同时打开。

等几天 / 贴膜

设备安装本身不用晾。但混水中心、分水器、阀门在后续施工里最怕被水泥浆和油漆糊死——装完立刻包气泡膜/编织袋，检修口不要封死。地暖第一次升温不在这一步，要等回填和贴砖都干透（见第 8 章）。

你怎么验收 建议到场

  • 立管还在，上下通用手摸立管保温是否包满；问工人有没有割过，看切口。
  • 能指出阀门 A 和阀门 B你自己能独立开关，标牌清楚。试一下：开 A 时 B 是关的。
  • 楼道预留口看得到堵头和阀门两根管子都有，套了保温，没有裸铜裸塑过冬。
  • 混水中心有泵、有混水阀、有过滤器、有两块表缺任何一件都等于高温直供，当场要求补。
  • 分水器水平、距地够高、路数对得上房间厨房阳台必须有独立一路。卫生间建议有一路，马桶落水处盘管绕开。
  • 板换位置空着但能装得下检修空间不要被橱柜或杂物柜占死。

选什么

材料首选可接受备选直接拒绝
盘管 乔治费歇尔 或 伟星 PE-RT II 型 + EVOH，De20×2.0mm 日丰同规格 II 型阻氧管 I 型冒充 II 型；无 EVOH；回收料发黄有黑点；无喷码
XPS 保温板 华美 / 绿羽 / 法宁格，3cm，密度 ≥30kg/m³，压缩强度 ≥250kPa 陶氏、欧文斯科宁（能买到更好） EPS 泡沫板（白色颗粒一掐一个坑）；标 3cm 实际 2cm
反射膜 伟星 / 日丰 / 绿羽配套真铝箔 同档真铝箔无纺布复合 透光的 PET 镀铝膜（胶带一撕大面积掉铝）
回填 豆石混凝土 C15–C20，豆石 5–15mm 圆形 — 纯水泥砂浆无石子；碎石片/瓜子片（棱角扎管）
边界条 EVA/PE 发泡条，厚 ≥8mm，有回弹 — 拿保温板边角料切割替代

执行标准对照：盘管 GB/T 28799.2-2020；XPS GB/T 10801.2-2025；地暖施工 JGJ 142-2012。管身/板面喷码必须能对上检验报告上的型号。

怎么做

  1. 找平：2 米靠尺缝隙 ≤5mm。老楼刨完往往坑洼，不平就铺保温板，后面全是波浪。
  2. 边界保温条：沿墙脚满贴一圈，房间超过约 30㎡ 或边长超过 6m 还要留伸缩缝。
  3. XPS：拼严、缝贴胶带。手按要硬实。太原建议 3cm，别让工人改成 2cm「省层高」。
  4. 反射膜：铝面朝上，搭接 ≥50mm，墙脚上翻 ≥50mm。
  5. 盘管：客厅卧室间距 15–20cm，厨卫 10–15cm，误差 ≤10mm。弯曲半径 ≥5 倍管径（De20 至少弯 100mm）。卡钉固定，禁止填充层内接头。
  6. 打压：0.6–0.8MPa，稳压 1 小时压降 ≤0.05MPa，再保压 24 小时。回填时压力表一直挂着，不撤压。
  7. 回填：人工木耙摊铺，禁止铁锹直接砸管子上。管上覆盖 ≥30mm。老楼不要无故加厚，湿式地暖 + 地砖大约增加 80–120kg/㎡，3 层一般能扛，但别再叠很厚砂浆。

墙边还有一圈边界保温条，图里没画。厨卫在回填层上再做生活防水，再贴砖。

等几天 / 贴膜

步骤最短等待缩短会怎样
找平层干透再铺保温板3–7 天保温板受潮，保温变差
盘管打压稳压 1h + 保压 24h微漏测不出，回填后只能砸地
回填洒水养护每天洒水 3–7 天混凝土开裂，管子可能露出来
回填干透再贴砖再等 7–14 天空鼓脱落；工人说「3 天就能贴」是偷工

回填后地面不要铺完全密封的塑料布长时间捂着，会闷裂。可以铺湿麻袋/土工布保湿养护。分水器一直包着防水泥浆。

你怎么验收 打压必须到场

  • 材料喷码和报告一致管身要有 II 型、EVOH、De20×2.0、GB/T 28799。报告上有 CMA/CNAS，编号能查。
  • 保温板 3cm、按压不塌带尺子量。白色颗粒泡沫板当场退货。
  • 胶带测反射膜透明胶带粘上去用力撕，大面积掉铝 = 镀铝膜，不合格。
  • 间距、弯头、无接头自己拿卷尺抽查。看见地面热熔接管立刻叫停。
  • 打压看表 + 摸接头0.6–0.8MPa，24 小时不掉。干纸巾擦分水器每个铜接头，湿了就是渗。拍视频，把表盘和时间拍进去。
  • 回填时压力表还挂着撤压再回填等于盲封。豆石必须是圆的，不是碎石片。
  • 回填后看开裂和伸缩缝房间超过 6 米或约 30㎡ 必须留伸缩缝。表面要平整，不能有露管。

6 种地暖材料进场（第一天必须做）

材料进场你必须到场，做三件事：索要证书 → 核对参数 → 拍照留档。材料不合格，工艺再好也白搭。出厂合格证是厂家自己出的，含金量低；型式检验报告是第三方出的，有法律效力，两个都要，缺一个不让施工。

喷码和报告对不上，当场拒绝开工
  • 索要：每样材料要出厂合格证 + 型式检验报告
  • 核对：管身/板面喷码上的标准号、型号，与报告是否一致
  • 拍照：材料、喷码特写、合格证、检验报告全部存档——日后维权的第一证据

3b长期性能怎么当场验（不用等 50 年）

「阻氧层防腐蚀」「反射膜不氧化」「管子 50 年不裂」，你不可能等 50 年去验证。这不是你的问题，是验收方法的问题。把验收分成两类：当场能测的，和靠报告替你验的。

第一类：当场能直接验

尺寸、间距、压力、外观、材质。拿卷尺、靠尺、压力表当场测。

第二类：长期性能 —— 有人替你做了加速老化实验

型式检验报告是第三方实验室出的，把 50 年老化压缩到几个月测完。你看报告数据达标，就等于间接验证了长期性能。

检测项目怎么测合格标准
阻氧层氧气渗透率40℃ 持续加压≤0.1g/m³·d
管材长期静液压强度指定温度和压力下持续加压几千小时不破裂
反射膜附着力剥离强度测试铝层不脱落

报告也可能造假，确认三件事：

  1. 有 CMA 或 CNAS 标志——没有这个章 = 废纸
  2. 报告上的产品型号、品牌和进场材料完全一致——对不上就是拿别的产品的报告糊弄你
  3. 报告编号能在检测机构官网查到——PS 造假的去官网一查就穿

大品牌在正规渠道不敢在报告上造假，一次曝光整个品牌就完了。杂牌白牌没有这个约束。

现场快速替代测试（进场当天就能做）

长期性能你没法等的事现场替代验证
阻氧层是否有效几年后管道腐蚀喷码有无「EVOH 阻氧层」+ 报告氧气渗透率
反射膜铝层持久性几年后氧化脱落透明胶带粘上用力撕，大面积脱落 = 劣质镀铝膜
管材柔韧性几年后开裂漏水拿一截用力弯到极限，好管子不裂；回收料发白甚至裂开
保温板密度受潮后塌陷指甲掐表面不留深痕 = 密度够；一掐一个坑 = 太松
分水器材质内部腐蚀漏水掂重量（铜更重）+ 断面金黄色
一句话
你的任务不是做 50 年实验，而是确认：替你做实验的人有资质（CMA/CNAS）、产品对得上、品牌跑不掉。再配合几个现场小测试兜底。

4厨卫冷热水：走顶、开槽、防冻

有地暖，给水管不走地面。厨房在阴面阳台，太原冬天水管冻裂是真事，这一章按「防冻 + 防漏」来。

选什么

全屋统一热水管

首选伟星 PP-R S2.5（冷水也用这个）
备选日丰 S2.5 同规格
主管 De25×3.5mm，分支 De20×2.8mm。管件必须同品牌。管身不透光，有涉水卫生批件，执行 GB/T 18742。

下水：PVC-U，联塑 / 中财。横管坡度 ≥1%–2%。马桶能不移位就不移。

怎么做

横干走顶 + 竖分走墙

  • 横向干线走厨卫铝扣板吊顶，电上水下，吊卡打进楼板，不搭龙骨
  • 竖向到龙头、花洒、马桶角阀，走墙竖槽
  • 冷热分槽，间距 ≥10cm；管卡 50–60cm 一个
  • 热熔 260–280℃，加热 5–8 秒，插接后保持 5 秒自然冷却，禁止浇水降温
等几天 / 贴膜

封槽前打压，不用晾管

打压 0.8–1.0MPa，保压 30–60 分钟。合格再封槽。热熔接头不要马上受力。吊顶内和靠外墙的冷热水管全部套 9mm 闭孔橡塑保温棉（华美 / 坤耐）。

你怎么验收

看表、擦接头、对光看管

  • 压力表不掉；干纸巾擦所有接头不湿
  • 对光：管子不透光
  • 冷热间距够，没有同槽
  • 拍全屋水路走向，以后打孔避开

开槽规矩（老楼尤其重要）

位置可以不可以
承重墙浅竖槽，刚够埋管横槽切断钢筋；开很深
非承重墙竖槽为主；横槽单面墙 ≤50cm一面墙横向开很长一圈
厨卫墙竖槽必须开（龙头、花洒都在墙上）开完槽不刷防水就埋管
地面地暖盘管自己走给水管、电线再走地
厨卫槽内防水（工人最爱省的一步）

开槽 → 清灰 → 槽内刷防水 1–2 遍 → 干透再埋管 → 封槽 → 封槽面再和大面一起刷防水。淋浴区、厨房水槽区必须做。不做的后果：瓷砖表面看起来没问题，水顺着管壁缝渗进墙里，发霉、渗到隔壁或楼下。

阴面阳台厨房：防冻四条
  • 厨房必须做地暖——阴面阳台冬天不供暖，地漏和水盆下水管也会冻
  • 水管从室内吊顶过来，不走外墙夹层——外墙里的水，停暖几天就能冻裂
  • 吊顶内和靠外墙的管子全部套保温棉——冷水管也套，夏天还能防冷凝水滴吊顶
  • 阳台封闭不严就先补窗——窗户已定不换，至少发泡胶填缝 + EPDM 密封条 + 厚窗帘。否则再好的管子也扛不住穿堂风

  • 热熔不到位温度不够或时间不够，接头未融合，当时不漏，几个月后渗，埋墙里发现时墙已泡透。
  • 热熔过度或浇水降温内壁熔塌堵管；浇水急冷开裂。必须自然冷却。
  • 冷热同槽或间距不够冷凝水长期泡墙发霉。间距 ≥10cm 且不同槽。
  • 给水管走地有地暖更不能走地。走顶漏了拆吊顶能修，走地要砸地暖。
  • 封槽前没打压封了才发现漏只能砸墙。
  • 回收料、透光管、管件不同品牌管身发黄有黑点；对光能看见里面；接头是最薄弱点。

    • 5强电弱电：走墙走顶，不走地

    地暖把地面占满了，线管再走地会被混凝土裹死，以后换线拉不动。客厅卧室走墙竖槽；厨卫横干走顶、竖分走墙。强弱电分管、分色。

    选什么

    材料首选可接受备选直接拒绝
    线管 联塑阻燃 PVC，壁厚 ≥1.5mm；红管强电、蓝管弱电 中财 / 伟星同规格 薄壁一踩就碎；非阻燃；强弱电同管
    电线 远东 ZC-BV 阻燃铜芯 熊猫 / 正泰 / 德力西 铜芯发黑；标 2.5 实际不足；无 CCC
    网线 康普或安普 超六类 Cat6A，UTP 23AWG 同规格一线品牌 Cat6A 七类/八类（家装用不上还难做）；无品牌白牌
    接线 WAGO 221 系列 合格螺旋端子 拧线 + 电工胶布；墙内直接接头
    线径不要让工人「看着来」：照明 1.5mm² · 普通插座 2.5mm² · 厨房/空调 4mm² · 小厨宝 2000W 必须单独一路 2.5–4mm² · 冰箱单独 2.5mm²。穿线率不超过管内截面积 40%（一根 16mm 管最多大约 3 根 2.5mm²）。老房子加地暖、小厨宝、净水器、洗碗机后用电量大增，配电箱总开考虑 63A，看入户线径是否要增容。厨卫回路装漏电保护。

    电线和线管怎么验（指南原文标准）

    项目优质标准怎么看
    电线材质铜芯，BV 单芯硬线或 BVR 多股软线看线身喷码
    铜芯颜色紫红色有光泽、粗细均匀发暗发黑 = 杂质铜/回收铜
    绝缘层阻燃 PVC，点燃离开火源自熄可烧一小段测试
    认证CCC 强制认证，GB/T 5023线身喷码和合格证
    长度标 100 米的盘不短斤少两劣质常不足米
    线管阻燃 PVC 硬管，壁厚 ≥1.5mm，常用 16 或 20mm卡尺量；脚踩不碎、弯折不裂
    强弱电平行 ≥30cm，交叉包锡箔当场量
    接头必须在接线盒内严禁墙内直接接头
    弯曲要有弧度，方便以后换线禁止直角死弯

    怎么做

    • 客厅卧室：沿墙竖槽到开关插座或上到顶再水平走（水平段尽量走顶部，少开横槽）。
    • 厨卫：干线走吊顶贴近楼板（电上水下）；落到开关插座、烟机、热水器的竖槽走墙。
    • 强弱电平行间距 ≥30cm，交叉时 90° 并在弱电外包锡箔。
    • 线管弯曲要有弧度，禁止直角死折（以后换线拉不动）。管卡 80–100cm 一个。
    • 配电箱在餐厅，总开考虑 63A，厨卫回路装漏电保护。弱电箱在客厅电视墙下方（已定），光猫放电视柜上不塞箱里。

    等几天 / 贴膜

    穿线、绝缘测试通过再封槽，线管本身不用晾。配电箱、弱电箱装完用纸板挡住，防止后续刮腻子、喷漆糊进去。封槽砂浆干 1–2 天再进行墙面下步。

    你怎么验收 封槽前到场

    • 红蓝分管，没有同管混走脚踩线管不碎；卡尺量壁厚 ≥1.5mm。
    • 线身喷码 + 铜芯紫红剥一小段看铜，发暗发黑退货。用卡尺核对线径。
    • 墙内无接头，接头在接线盒打开几个底盒看是不是 WAGO。
    • 摇表绝缘 ≥0.5MΩ，各回路单独送电不跳闸小厨宝那一路必须单独空开。
    • 强弱电间距、网线 Cat6A 喷码全屋点位按已定方案：约 9 条网线 + 1 条光纤预埋。拍照存档。

    6防水和闭水（厨房按卫生间做）

    厨房在阳台，有洗菜、有地漏、冬天还可能结露。不要听「厨房不用做那么认真」。漏水修一次，比多刷两遍防水贵十倍，而且会泡地暖层。

    选什么

    柔性防水，正规渠道

    首选东方雨虹 / 德高 JS 或优质柔性防水
    备选科顺、西卡、汉高同档
    拒绝沥青基臭料、来路不明的「防水胶」、只刷一遍就说完了。

    地面干膜厚 ≥1.5mm，墙面 ≥1.2mm。干透后可在边角割小块取样测厚，太薄等于没做。

    怎么做

    先附加层，再十字交叉

    • 地暖回填层之上做生活防水（防洗漱水下渗）
    • 阴阳角、管根、地漏先刷一遍 + 贴无纺布
    • 地面满做 2–3 遍，干膜厚 ≥1.5mm
    • 淋浴区墙面做到 ≥1.8m；厨房水槽墙同样做
    • 门槛上翻 ≥10cm，包过门槛石两侧
    等几天

    遍遍等干，闭水 48 小时

    • 每遍表干 2–4 小时（手摸不粘）
    • 最后一遍完全干 24–48 小时再闭水
    • 蓄水 ≥20mm，48 小时
    • 合格后做水泥砂浆保护层，再等 24 小时
    你怎么验收

    下楼看天花板

    • 闭水期间自己下楼看，不止看表
    • 水位有没有明显下降
    • 门槛处防水是否翻上去了
    • 没闭水不许贴砖
    闭水试验怎么做才算数
    • 地漏、下水口用气囊或沙袋堵严，蓄清水，高出地面至少 20mm（有条件 30mm 更好）
    • 在墙上用铅笔画一条水位线，48 小时后还在这条线附近
    • 必须去楼下邻居家看天花板、管根、墙角，有无湿印、掉皮。只看自家地面不湿，测不出慢渗
    • 冬季室内低于 5℃ 不要做防水和闭水，会冻、会假干

    闭水合格到贴砖之前，防水层最怕踩坏：做完保护层，工人换鞋或垫木板。鞋底石子划破等于白做。

    防水子步骤（工序最多、最容易偷工）

    子步骤工序等待
    1基层清理，阴阳角做圆弧，管根/地漏周边修补平整—
    2附加层：阴阳角、管根、地漏先刷一遍 + 贴无纺布（90% 漏水从这里开始）2–4 小时表干
    3第一遍防水（纵向）2–4 小时，手摸不粘
    4第二遍防水（横向，十字交叉）2–4 小时
    5第三遍（地面建议 3 遍）24–48 小时完全干透
    6闭水 ≥20mm48 小时，下楼看
    7合格后水泥砂浆保护层24 小时

    7瓷砖：全屋柔光，厨卫防滑，适老化无高差

    亮面砖在展厅里好看，家里有老人、有地暖、还要拖地，并不合适：湿滑、显脚印、反光刺眼。客卧用柔光/哑光瓷质砖，厨卫地面用防滑砖。

    推荐结论
    客厅卧室过道：600×600 柔光瓷质砖。卫生间、厨房地面：防滑砖（R10/R11）。墙面：300×600 柔光。品牌用东鹏 / 马可波罗 / 诺贝尔中端即可，不必上简一。

    老房墙多、房间不一定方正，600×600 比 800×800 更好铺、损耗更低。房间特别方正再考虑 800×800。同一空间必须同一色号批次。

    选什么

    区域规格表面关键指标
    客厅、卧室、过道、餐厅 600×600（首选）；方正再考虑 800×800 柔光 / 哑光 瓷质砖，吸水率 ≤0.5%，厚度 ≥10mm，通体或优等釉面
    卫生间地面 300×300 或 600×600 防滑 R10/R11，麻面或微凹凸 湿态摩擦系数高；坡向地漏，无积水
    卫生间墙面 300×600 柔光即可 淋浴区铺到顶；阴阳角用阳角条
    厨房地面（阴面阳台） 防滑地砖，规格同卫生间地面 防滑 油污区也要能站稳；保留原地漏
    厨房墙面 300×600 柔光 灶台、水槽墙满铺，便于擦油
    瓷砖胶和美缝（地暖上这是死规定）
    瓷砖胶 C2TE 或 C2TES1
    首选德高、西卡、马贝、东方雨虹的柔性瓷砖胶。地暖会热胀冷缩，普通水泥砂浆贴大砖，空鼓开裂是时间问题。大砖（≥600）必须齿形刮板满浆 + 背面补涂（背涂）。
    留缝和美缝
    砖缝 2–3mm。地暖房间四周靠墙留伸缩缝，美缝剂不要把伸缩缝填死，用弹性硅酮。厨卫美缝用环氧彩砂更耐污（德高 / 卓高）。

    怎么做

    1. 回填干透、厨卫闭水合格、保护层干了，才能弹线排砖。
    2. 基层 2 米靠尺 ≤3mm。地暖地面不要再厚厚抹一层砂浆找平，能薄贴就薄贴，利于导热、也减轻荷载。
    3. 瓷质砖一般不泡水（看背面吸水率说明）；陶质砖才需要泡。不要听「所有砖都要泡一夜」。
    4. 从门口或房间中线排砖，把半砖藏到边角。厨房超薄地轨（凸出 ≤8mm）在铺砖时嵌入找平，尽量与地砖齐平，适老化、不绊脚。
    5. 全屋尽量无高差：卫生间、厨房与过道用微坡 + 同厚门槛石过渡，不要做 3–5cm 高台阶。
    6. 贴完用十字卡和调平器，橡皮锤敲实，擦净缝里余胶。

    等几天 / 贴膜

    步骤最短等待说明
    贴完到上人24–48 小时不到时间踩会松动。厨卫墙砖同样等。
    勾缝 / 美缝砖稳之后缝里余胶先抠干净。
    贴保护膜砖稳、表面干用编织布或珍珠棉，接口胶带粘在膜上，不要粘砖面。不要用完全密封的塑料布长时间捂潮。
    地暖第一次升温贴砖后再等约 21 天每天只加一点温度，禁止一上来开到最高。回填和胶都要慢慢适应热胀。

    后期刮腻子、吊顶、橱柜都在保护膜上作业。分水器、阀门、检修口不要封死。完工再揭膜，边揭边检查划伤。

    你怎么验收（全屋地面）

    • 空鼓：硬币或小木槌逐块敲四角和中心清脆 = 贴满了；空洞发闷 = 空鼓。地砖尽量零空鼓；墙砖单片空鼓率 ≤5%，中心不许空。大面积空鼓要返工。
    • 平整度：2 米靠尺 ≤2mm，相邻砖高低差 ≤0.5mm带靠尺和塞尺，抽客厅、过道、卫生间各测几处。
    • 缝宽一致，无大崩边地暖房间靠墙伸缩缝还在，没有被美缝填死。
    • 厨卫泼水试验水应流向地漏，无倒坡、无积水。门槛石两侧都有防水上翻的痕迹（贴砖前就该拍过照）。
    • 防滑和适老化卫生间、厨房湿着走不打滑；全屋没有高门槛；厨房门轨道不明显凸起绊脚。
    • 色号批次一致同一房间砖色没有一块深一块浅。进场时箱上批次号要拍照。
  • 用水泥砂浆贴 600 以上的砖地暖上必空鼓。合同写死 C2TE/C2TES1。
  • 亮面砖铺客卧老人滑倒风险高，脚印和刮痕特别显。
  • 厨卫做高台阶「挡水」挡水靠防水和微坡，不靠绊脚石。家里有老人，无高差优先。
  • 贴完当天让木工进场踩砖还没粘住，整面都会松。
  • 地暖刚贴完砖就点火胶和回填会被热应力拉开。

    • 8墙面基层（老房必须铲到砖）

    老房原有腻子多半不耐水。不铲干净直接批新腻子，是后期乳胶漆起皮脱落的第一原因，也是最常见的返工。

    选什么

    耐水腻子 + 墙固

    首选美巢 / 莱恩斯 / 百得 / 立邦
    腻子必须是耐水 N 型，执行 JG/T 298。墙固（界面剂）：美巢、东方雨虹、百得。阴阳角贴 PVC 角条。

    怎么做

    铲 → 浇水试 → 墙固 → 石膏 → 腻子

    1. 铲到砖墙或水泥层
    2. 浇水测试：老腻子遇水起泡、手搓掉粉 = 没铲干净
    3. 清浮灰，滚涂墙固一遍
    4. 裂缝开 V 槽，贴网格布/牛皮纸，石膏填缝
    5. 粉刷石膏粗找平，再两遍耐水腻子精找平
    6. 砂纸打磨
    等几天

    每遍腻子之间必须 24 小时

    • 墙固干 2–4 小时
    • 裂缝石膏干 24 小时
    • 粗找平干 24 小时（厚则更久）
    • 第一遍腻子干 24 小时
    • 第二遍腻子干 24–48 小时再打磨

    赶工期一天刷两遍腻子 = 必然起泡开裂。

    你怎么验收

    浇水 + 夜间手电

    • 铲墙后浇水，不起泡不掉粉
    • 裂缝处能看到网格布
    • 打磨后、刷漆前：夜间用强光手电贴墙侧照，有波浪纹就返工
    墙面基层偷工清单
    • 老墙皮没铲干净就批腻子 → 后期起皮脱落
    • 用非耐水腻子 → 受潮粉化发霉
    • 裂缝没贴网格布 → 几个月后裂缝再现
    • 腻子没干透就打磨 → 继续收缩开裂
    • 不贴阴阳角条 → 角不直

    9吊顶内隐蔽工程

    厨卫已定铝扣板、轻钢龙骨。封板之前，排风管和线管必须走完。本户分水器在餐厅，检修口开在餐厅，厨房吊顶不用为分水器留口。

    选什么

    轻钢龙骨 + 铝扣板

    厨卫：铝扣板，板厚 ≥0.5mm，哑光白/浅灰，300×600。龙骨用轻钢防锈，不用木龙骨（厨卫蒸汽大，木龙骨受潮变形）。排风管：铝箔软管，卡箍 + 铝箔胶带密封。烟机直排窗外，墙洞吊顶前先打好，口径 160/180mm + 止逆阀 + 防雨帽。

    怎么做

    先走管，后封板

    1. 弹线，膨胀螺丝固定吊杆
    2. 装主龙骨 + 副龙骨，调平。检修空间 ≥15cm
    3. 排风管、线管、水管先走完（电上水下，吊卡打到楼板，不搭龙骨）
    4. 封铝扣板
    5. 餐厅分水器正上方留检修口 ≥30×30cm
    等几天 / 贴膜

    封板前是最后窗口

    吊顶本身不用晾。封板后想补管就要拆。分水器、阀门不要被扣板封死。

    你怎么验收 封板前到场

    三件事

    • 排风管卡箍固定、接口密封，捏一捏不晃
    • 没有裸线，全是 PVC 管
    • 检修口对准分水器，打开能伸手进去
    吊顶偷工
    • 木龙骨替代轻钢龙骨
    • 排风管没固定 → 共振嗡嗡响
    • 封板后才走排风管 → 要么拆板，要么干脆不接
    • 检修口漏留或被柜子挡住 → 修分水器要拆吊顶

    10门窗密封（老窗不换，低成本补救）

    窗户已定不换（20 年老窗保温差）。发泡胶填缝 + EPDM 密封条 + 厚窗帘，是预算内最划算的补救。阴面阳台厨房防冻也靠这一步。

    选什么

    发泡胶 + EPDM 密封条

    发泡胶：聚氨酯，桑莱斯 / 固诺 / 东方雨虹 / 汉高。
    密封条：三元乙丙（EPDM），耐候耐老化。拒绝劣质 PVC 密封条（几年后发硬开裂）。

    怎么做

    缝打满，窗台向外坡

    • 框与墙的缝打满发泡胶，充分膨胀后切平
    • 窗扇四周换 EPDM 密封条
    • 窗台必须向外倾斜排水
    等几天

    发泡胶膨胀后再切

    按产品说明等膨胀完成（通常几十分钟到数小时）再切多余的。切完再做窗套，避免把没发泡实的空洞盖住。

    你怎么验收

    看空洞、试倒水

    • 填缝无空洞，手电照缝不透光
    • 密封条按压有弹性，不是发硬的塑料
    • 窗台倒一点水应向外流，不能倒灌进屋

    11墙面刷漆

    腻子打磨合格之后才刷。底漆一遍 + 面漆两遍。省底漆、面漆只刷一遍，当时看不出来，入住后色差和不耐擦都会暴露。

    选什么

    底漆 + 面漆配套

    品牌可与腻子同一体系（立邦、多乐士等中端即可）。底漆和面漆尽量同品牌配套。面层可以选中档，不必上最贵的。

    怎么做

    清灰 → 底漆 → 两遍面漆

    1. 腻子打磨后清理浮灰
    2. 刷底漆一遍
    3. 刷第一遍面漆
    4. 刷第二遍面漆
    等几天

    遍遍等干

    • 底漆干 2–4 小时再刷面漆
    • 第一遍面漆干 2–4 小时再刷第二遍
    • 第二遍面漆干 24 小时再碰墙、贴膜
    你怎么验收

    色差、起泡、漏刷

    • 无漏刷、无流坠
    • 无起泡（底漆没干就刷面漆会起泡）
    • 侧光看颜色均匀
    刷漆偷工
    • 没刷底漆直接刷面漆 → 附着力差、色差、费面漆
    • 底漆没干就刷面漆 → 起泡
    • 面漆只刷一遍 → 遮盖力不够、不耐擦洗

    12总工期时间轴：哪天必须你到场

    太原气候偏干，同样工序比南方略快，但该等的仍要等。室内低于 5℃ 不要做防水、回填、腻子。施工方催「3 天就能贴砖」，拿出这张表对照。装修最容易被偷的不是材料，而是等待时间——该等的不等，当时看不出来，入住后全部暴露。

    必须本人到场的节点（建议打印）
    • 材料进场当天地暖管、PPR、电线、线管、XPS、防水涂料、瓷砖胶、瓷砖。对喷码、合格证、型式检验报告，拍照。
    • 水电布完、封槽前水路打压 0.8–1.0MPa；电路绝缘和通电；拍管线走向。
    • 双热源阀门和混水装完确认立管未断、A/B 不能同时开、楼道预留口在。
    • 地暖盘管铺完、回填前打压 24 小时，拍压力表视频。回填时再看一眼表还挂不挂。
    • 防水闭水 48 小时自己下楼看天花板。不合格不许贴砖。
    • 贴砖后空鼓和平整度敲遍地砖，靠尺抽查，厨卫泼水。
    • 铲墙后浇水测试铲到结构层，遇水不起泡不掉粉。
    • 腻子打磨后、刷漆前夜间强光手电贴墙侧照，无波浪纹。
    • 吊顶封板前电上水下、排风管已固定、餐厅分水器正上方有检修口。
    • 门窗打胶后发泡胶无空洞，密封条是 EPDM，窗台向外坡。
    贴膜保护记三句话
    • 砖稳了再铺编织布/珍珠棉，胶带粘膜不粘砖
    • 不要用完全密封塑料布长时间捂潮
    • 分水器、阀门、检修口留出来，方便以后打压和排气

    13进场材料速查表（可打印带去工地）

    原则：首选写进合同；备选只有首选买不到时才换，且参数不能降；拒绝项出现就停工退货。品牌是参考，参数和认证对不上照样退。

    材料首选关键参数（盯死）现场怎么验
    地暖盘管 乔治费歇尔 / 伟星 PE-RT II + EVOH De20×2.0；II 型；EVOH；GB/T 28799.2-2020 喷码；对光透亮无黑点；弯折不裂
    XPS 华美 / 绿羽 / 法宁格 3cm 密度 ≥30；压缩 ≥250kPa；导热 ≤0.030；B1 量厚度；指甲掐不留深痕；拒泡沫颗粒板
    反射膜 伟星 / 日丰 / 绿羽真铝箔 不透光；铝层撕不掉 胶带测试
    混水中心 曼瑞德 / 丹佛斯 泵 + 混水阀 + 过滤器 + 两块表 缺件不装
    分水器 曼瑞德 / 丹佛斯 / 意瓦 黄铜锻造；壁厚 ≥2.6mm；≥1.0MPa 掂重；看断面金黄；无焊缝拼接
    PPR 水管 伟星 S2.5 主管 De25 / 分支 De20；管件同品牌；卫生批件 不透光；喷码 S2.5
    PVC 线管 联塑阻燃 壁厚 ≥1.5mm；红强电蓝弱电 脚踩不碎
    电线 远东 ZC-BV CCC；照明 1.5 / 插座 2.5 / 厨空 4 铜芯紫红；卡尺量线径
    网线 康普 / 安普 Cat6A 23AWG UTP 护套喷码
    防水 雨虹 / 德高 JS 或柔性；地面干膜 ≥1.5mm 正规渠道防假；闭水 48h
    瓷砖胶 德高 / 西卡 / 马贝 / 雨虹 C2TE 或 C2TES1 包装等级字样；拒普通砂浆贴大砖
    地砖 东鹏 / 马可波罗 / 诺贝尔中端柔光 吸水率 ≤0.5%；厚 ≥10mm；客卧柔光、厨卫地防滑 同一批次色号；拒亮面客卧
    回填豆石 现场看料 5–15mm 圆形；水泥:砂:豆石约 1:2:3 有棱角碎石片立刻停工
    腻子 / 墙固 美巢 / 莱恩斯 / 百得 / 立邦 耐水腻子 N 型，JG/T 298 看包装「N 型」；非耐水遇潮粉化

    边界保温条 EVA/PE 发泡条 厚 ≥8mm，有回弹 拒保温板边角料切割替代

    验收节点一览（建议打印）

    序号工程节点必做检查
    1地暖材料进场当天合格证 + 型式检验报告（CMA/CNAS），喷码与报告一致，拍照
    2分水器安装后水平牢固、距完成地面 ≥300mm；餐厅正上方留检修口
    2a双热源混水装完立管未断；A/B 不能同时开；楼道预留口有阀门+堵头+保温；混水含泵/阀/过滤器/两块表
    3保温板铺设后3cm、密度、拼接无缝
    4盘管回填前间距误差 ≤10mm、弯曲半径 ≥5 倍管径、填充层内无接头
    5盘管打压回填前≥0.6MPa 保压 24h 不掉，拍视频
    6回填回填时管内保压不撤、木耙摊铺、覆盖 ≥30mm
    7回填后养护后无开裂、有伸缩缝、表面平整
    8水路封槽前0.8–1.0MPa 保压 30–60min；拍照走向
    9电路封槽前穿线率 <40%、强弱电 ≥30cm、无墙内接头、各回路通电、拍照走向
    10防水贴砖前2–3 遍、门槛上翻 ≥10cm、闭水 48h 下楼看
    11墙面基层铲墙后 / 刷漆前铲到结构层浇水测试；夜间手电无波浪纹
    12吊顶内封板前排风管固定、检修口对准分水器
    13门窗打胶后发泡胶无空洞、EPDM 密封条、窗台外坡
    14瓷砖地面贴稳后空鼓、平整度、厨卫坡度、无高差
    最后提醒
    • 隐蔽工程材料尽量自己买，或品牌型号写进合同附件。让施工方「包料」最容易被换成杂牌。
    • 每个验收节点合格才付下一笔款。一旦封槽/回填/贴砖，就再也看不到了。
    • 管线走向、打压表盘、闭水下楼，全部拍照录像——日后维权的第一证据，后期打孔也能避开管子。
    • 该等的等待时间一天都不能少。缩短等待是最大的偷工，当时看不出来，入住后全暴露。
    • 找装修公司还是找朋友施工，标准是同一个，区别只是谁来执行、出了问题谁负责。
