0今天拍板的 5 条（覆盖原先红底分歧）

下面 5 条是统一口径。工人、装修公司、自己买料，都按这一版，不再引用两套旧文里互相打架的数字。

1. 供暖必须兼容两套热源。现在用单位锅炉，以后接市政大暖时只接楼道预留口，户内地暖盘管不用再砸。必须上混水，高温水不能直灌地暖。
2. 地面全部铺砖，不铺木地板。厨卫用防滑砖。客厅、卧室、过道的砖面是亮光还是柔光，下面单独给你一个看样对照，进场前选定色号即可。
3. 柜子本期不做。柜体、门板、台面不进本期合同。厨房水电仍按以后能装柜预留（水槽、小厨宝、净水器点位不能省）。
4. 照明线用 2.5mm²。全屋照明回路按 2.5 平方铜芯，不再写 1.5。
5. 承重墙上可以有插座和网口。允许为底盒开浅竖槽。禁止在承重墙上开长横槽、禁止伤钢筋、禁止动梁柱。横着走线优先走吊顶再竖着落下。
两套旧文怎么用

《硬装小白实施手册》继续当「工序、等待天数、你哪天到场」手册用；wb 专题页继续当「图怎么验、弱电点位图、厨房门轨道」补图用。参数和做法以本页为准。

1供暖：现在锅炉，以后大暖，一套地暖兼容

单位锅炉和以后市政二次网的水，大约 50–70℃；地暖只要 35–45℃。高温直灌会烫地面、空鼓、缩短管子寿命。两套热源还不能同时开，否则可能顶压邻居、污染管网。

统一接法
立管保留 → 阀门 A 接现在的单位锅炉；楼道预留口 → 阀门 B 接未来大暖；两路汇到过滤器 + 混水中心，再进餐厅铜分水器。

户内板式换热器现在不买，只留位置和接口。等热力公司进场如果要求隔离，再加小型板换。大暖来了只接楼道那两根管，房内不用返工。

混水之后永远是低温水进盘管。盘管分不清水来自锅炉还是大暖——这就是「兼容」的意思。

写进合同的配件

配件统一要求
混水中心循环泵 + 恒温混水阀 + 过滤器 + 温度表 + 压力表。首选曼瑞德、丹佛斯；备选意瓦、金牛。拒绝「只有分水器、没有混水和泵」。
铜分水器装在餐厅。H59-1 黄铜、整体锻造、壁厚 ≥2.6mm。约 5–7 路：客厅、主卧、儿子房、厨房阳台、卫生间。底部距完成地面 ≥300mm。正上方吊顶留 ≥30×30cm 检修口。与配电箱间距 ≥30cm。
切换与预留阀门 A、B 用全通径铜球阀 + 止回阀，或一把三通切换阀互锁。楼道预留供+回，建议 De25，出墙加阀门和堵头，套 9mm 以上橡塑保温。打楼道墙前先问物业。没接通前阀门常关。
立管暖气片可拆，穿楼板的竖直供回水立管不能割断。本户用三通接管，立管上下仍贯通，包保温。
切换铁律

先关上正在用的那一路，停一两分钟，再打开另一路。阀门贴标签：「A 单位锅炉（现在用）」「B 市政大暖（预留，常关）」。禁止同时打开。

2地面：全屋铺砖，不铺木地板

木地板这条路关掉。地暖导热、防水、适老无高差、全屋没有材质交接压条，都按通铺瓷砖做。

已定
客厅、卧室、过道、餐厅、厨房、卫生间全部瓷砖。不要强化地板、不要实木复合、不要 SPC。

规格：客卧过道首选 600×600（房间特别方正再考虑 800×800）。厨卫地面用防滑砖（R10/R11）。品牌中端即可：东鹏 / 马可波罗 / 诺贝尔。瓷质砖吸水率 ≤0.5%，厚度 ≥10mm。同一空间必须同一色号批次。

亮光还是柔光——只有客卧过道需要你看样

厨卫已经能定：地面必须防滑，不能用亮面砖（湿了打滑，不适老）。真正要选的是客厅、卧室、过道、餐厅。

柔光 / 哑光（建议优先看这个）亮光 / 抛光
观感 不刺眼，更像石材或水泥质感，展厅里可能不如亮砖「闪」 展厅效果最好，空间显得亮、显大
脚印油渍 不明显，拖地压力小 反光一打，脚印、水渍、拖布印全显
老人防滑 干态更稳；仍要选柔光瓷质，不要纯釉面滑砖 干态也比柔光滑，过道转弯更容易滑
地暖灯光 反射弱，晚上吸顶灯不眩光 灯光和窗户会在地上拉一条光带
和全屋地砖的匹配 和厨卫防滑砖色差更好压，无高差通铺更自然 客厅很亮、进厨房突然变哑，交界处容易「两张皮」
看样板时怎么拍板（进砖前完成即可）
  • 让店里把同一色号的柔光和亮光各铺 4 块在地上，别拿手上的样块对着灯看。
  • 倒一小杯水再走两步：明显打滑的，客卧也不要。
  • 用手机手电贴地斜照：亮面像镜子，柔光只有一层淡光。
  • 家里有 70 多岁老人、全屋通铺、地暖 + 吸顶灯，默认选柔光更不容易后悔。只有你特别想要「亮堂堂的客厅」，再考虑客厅单独亮面——卧室和过道仍建议柔光。

贴砖工艺（地暖上这是死规定）

  • 柔性瓷砖胶 C2TE 或 C2TES1（德高 / 西卡 / 马贝 / 雨虹），禁止普通水泥砂浆贴 600 以上的砖。
  • 砖缝 2–3mm（地暖房留缝不能按 1mm「无缝」干）。靠墙伸缩缝用弹性硅酮，不要把美缝填死。
  • 厨卫美缝用环氧彩砂。客卧同样可用环氧彩砂。
  • 全屋尽量无高差：厨卫与过道用微坡 + 同厚门槛石过渡，不要做 3–5cm 高台阶。
  • 厨房超薄地轨（凸出 ≤8mm）铺砖时嵌入找平，尽量与地砖齐平。
  • 地砖尽量零空鼓；厨卫空鼓尤其要严。贴砖后再等约 21 天，地暖才允许首次缓慢升温。

3承重墙：插座和网口可以有，长横槽不行

老楼不砸墙，但客厅电视墙、过道、房间里难免有一面是承重墙。插座、网口必须上墙，完全不开槽做不到。统一口径不是「承重墙碰都不能碰」，而是怎么开才不伤结构。

统一开槽规则
承重墙上可以装开关、五孔、网口。每个点位用竖槽落到的底盒。横向干线尽量走顶部，到点位再竖着下来。

看到钢筋立刻停，改浅或改道。横梁、圈梁、构造柱上绝对不开槽。

左边两个竖槽、两个底盒，承重墙完全可以这样干。右边为了省事横向拉通，这才是真正伤楼的做法。

场景怎么做不能怎么做
承重墙上要 1 个插座或网口 从上方（吊顶或墙顶）开竖槽落到那个底盒。槽深刚好埋管，管壁距墙面再留约 10mm 砂浆。深度不超过墙厚的 1/3。 用锤子砸槽；开得很深碰到钢筋还继续打。
同一面承重墙上要 2–3 个点位 每个点位各自一条竖槽。水平连接走吊顶内或沿墙顶，再分别竖下来。强弱电仍然分槽、间距 ≥30cm。 在腰线高度开一条长横槽把几个底盒串起来。
相邻底盒必须横连（极少） 尽量改到非承重墙。实在避不开：单面短横槽尽量短（参照 ≤30cm），浅埋，让结构工人确认没有切筋。 绕房间开一圈横槽；双面墙对开；梁上开槽。
非承重墙 竖槽为主；横槽单面墙 ≤50cm。 一面墙横向开很长一圈。
厨卫墙 竖槽必须开（龙头、花洒、插座都在墙上）。开完先刷槽内防水再埋管。 厨卫墙开横槽（破坏防水和贴砖面）。
点位怎么规划，承重墙就会少挨刀
  • 电视墙、书桌、床头这些「必须上墙」的点位，提前在墙上用胶带标出来，能挪到非承重墙的尽量挪。
  • 挪不了的，就接受「多开几条竖槽」，不要为了少开槽改成横槽。
  • 弹墨线你要到场看一眼：竖的可以，横着拉长的当场改。

4水电弱电（照明已改 2.5）

走线大原则两套旧文已经一致，这里不再打架。只把线径按你的决定改掉，并收成一张表。

客厅 / 卧室
竖槽走墙。地面只铺地暖盘管，不走给水、不走电线。
厨房 / 卫生间
横干走铝扣板吊顶，竖分走墙。电上水下。槽内先刷防水再埋管。
全屋地面
不走给水、不走电线。走地等于焊死，坏了要砸地暖。

线管：联塑阻燃 PVC，壁厚 ≥1.5mm；红管强电、蓝管弱电；穿线率 ≤40%。强弱电平行 ≥30cm，交叉 90° + 弱电外包锡箔。接线用 WAGO 221，禁用拧线 + 电工胶布；管内、墙内禁止接头。

水管管卡 50–60cm；线管走顶 80–100cm，墙槽内宁密勿疏。转弯两端各加一个管卡。吊顶内吊卡打进楼板，不搭龙骨。

弱电位（已定，本期照做）

  • 配电箱在餐厅，与分水器间距 ≥30cm。
  • 弱电箱在客厅电视墙下方，≥330×480×135mm，箱内留 220V。光猫放电视柜上，不塞箱子里。
  • 网线：康普 / 安普超六类 Cat6A，UTP 23AWG。七类 / 八类不买。
  • 约 9 条网线 + 1 条光纤：客厅电视墙 2 + 光纤 / 儿子房 2 / 主卧 1 / 厨房 1 / 玄关 1 / 天花板 AP 预留 1 / 卫生间 1。
  • 光纤：弱电箱到电视墙预埋 G.657 蝶形光缆（非金属加强芯）+ 尼龙牵引绳。装修前打运营商电话，确认楼道到户内预埋管是否通。
  • 智能预留花不了多少钱：开关底盒尽量拉零线；窗帘盒可留插座。灯具本身：现有吸顶灯沿用；厨房只要最简单的吸顶灯，不要灯带、不要轨道灯。

5水路 · 地暖管 · 防水

冷热给水

伟星 PP-R S2.5 全屋（冷水也用热水管级别）。主管 De25×3.5mm，分支 De20×2.8mm，管件同品牌。热熔 260–280℃，加热 5–8 秒，自然冷却禁止浇水。封槽前打压 0.8–1.0MPa，保压 30–60 分钟。吊顶内和靠外墙的管子套 9mm 闭孔橡塑保温棉。厨房在阴面阳台：水管从室内吊顶过来，不走外墙夹层。厨房必须做地暖，防止地漏和下水管冻。

下水 PVC-U（联塑 / 中财），横管坡度 ≥1%–2%。马桶不移位。净水器进回水、小厨宝进出水在水槽柜下预留（即使本期不安橱柜，点位也要留）。

地暖盘管与回填

PE-RT II 型 + EVOH，De20×2.0mm，首选乔治费歇尔或伟星，备选日丰。客卧间距 15–20cm，厨卫 10–15cm，填充层内禁止接头。打压 0.6–0.8MPa，保压 24 小时，回填时压力表一直挂着。

层构造从下到上：原楼板 → 找平（靠尺 ≤5mm）→ XPS 挤塑板 3cm（≥30kg/m³、压缩 ≥250kPa，拒绝泡沫板）→ 真铝箔反射膜 → 盘管 → 豆石回填（5–15mm 圆形，管上覆盖 ≥30mm）→ 厨卫在这层之上再做生活防水 → 地砖。回填养护 3–7 天，再干 7–14 天才能贴砖。

防水与闭水

厨房按卫生间认真做（洗菜、地漏、冬天结露）。首选东方雨虹 / 德高柔性防水。地面干膜 ≥1.5mm；淋浴墙 ≥1.8m；厨房水槽墙同样做；门槛上翻 ≥10cm。阴阳角、管根、地漏先做附加层。闭水蓄水 ≥20mm（有条件 3cm），48 小时，自己下楼看天花板。合格后再贴砖。贴砖过程怕划破防水层，有条件可贴砖后再做一次二次闭水。

6吊顶 · 墙面 · 门窗 · 厨房门

项目统一做法
厨卫吊顶轻钢龙骨 + 铝扣板，板厚 ≥0.6mm（按更严的一档买），哑光白/浅灰，300×600。不用木龙骨。检修空间 ≥15cm。分水器检修口在餐厅，厨房吊顶不留分水器口。先走管后封板。
烟机直排窗外。墙洞 160/180mm + 止逆阀 + 防雨帽，吊顶前打好。
厨房门超薄地轨，凸出 ≤8mm，铝合金实心厚壁，尼龙密封轮，5mm 钢化玻璃门。铺砖时嵌入找平。
墙面基层老房铲到砖，浇水试。耐水腻子 N 型。墙固 + 两遍腻子，每遍间隔 24 小时。刷漆前夜间手电侧照。底漆 + 两遍面漆（立邦/多乐士中端）。
窗户不换。发泡胶填框缝 + EPDM 三元乙丙密封条 + 厚窗帘。窗台必须向外坡排水。可选冬季贴透明保温膜。
沿用保护拆旧时保护：2026 元旦新吸顶灯、马桶（法兰圈换新）、窗框、老家具和冰箱电视洗衣机。

7本期明确不做 / 暂缓

橱柜柜体、门板、台面 — 本期不考虑

不签柜体合同，不进板材，不做台面开孔。两套旧文里「颗粒板还是多层板」「台面 15mm 还是 20mm」全部搁置，以后单独再定。

但是水电不能跟着砍：水槽给排水、小厨宝单独回路、净水器进回水和电源、烟机点位、水槽柜下防水插座——这些埋进墙和顶里，后期再装柜才接得上。水浸传感器（厨房水槽下 + 卫生间）建议本期仍装，漏水会泡地暖层。

洗碗机：空间未定。建议水电先预留点位，装不装以后再说。

室内门、踢脚线、窗帘盒、开关面板具体品牌，属于面层收口，可以等墙地定色后再买；水电底盒和零线按弱电章预留即可。

  • 吊顶封板前电上水下、排风管已固定、餐厅分水器正上方有检修口。
最后三句
  • 隐蔽工程品牌型号写进合同附件。包料最容易被换成杂牌。
  • 每个节点合格再付下一笔。封槽、回填、贴砖之后就看不见了。
  • 该等的等待时间一天都不能少。缩短等待是最大的偷工。

9全屋材料品牌规格清单（主材+辅材，写进合同附件）

按 2026-08-17 统一方案整理，把冷热水管、地暖、电线、网线、接头、美缝、涂料、水泥沙子这些大件小件都写死。绿标=已定；黄标=建议（可等面层定色）；灰标=本期不做。报价单漏辅料、只写「水泥沙子另计」的，按这张表补进合同。

白话：是干啥的 冷热水管 地暖 下水 电线线管 网线接头 配电弱电 防水 水泥沙子 瓷砖胶美缝 腻子涂料 吊顶门窗 胶与密封 厨卫预留 不做与拒用

先看懂：每样东西是干啥的

下面不讲品牌。只讲「它在你家干什么、不装会怎样」。看懂这一节，再往下对品牌表。

水：从入户到水龙头、再流走

PPR 冷热水管：家里喝的、洗的自来水走的管子。冷水热水都用这种白塑料管，热熔焊成一根，埋进墙里顶里。

PPR 管件（接头）：弯头让管子转弯，三通让管子分叉去厨房、卫生间。管子和接头必须同一家，否则焊不牢会漏。

阀门：总开关。漏水或换龙头时能把这一路水关掉，不用全楼停水。

角阀 / 软管：藏在马桶、洗手盆、水槽下面的小开关和那段金属软管，接到龙头或马桶水箱上。

生料带 / 厌氧胶：拧螺纹接口时缠的白胶带（或液体密封胶），防止牙口渗水。热熔焊的 PPR 口不需要这个。

管卡：把管子钉在墙上或楼板上的卡子，免得管子晃、坠、通水时嗡嗡响。

保温套：套在热水管外的海绵管。冬天水不那么快凉，夏天管子上不结露往下滴水。

下水管（PVC）：脏水走的管子，比给水管粗。洗手、洗澡、马桶冲水都进它，再排到楼下立管。

PVC 胶水：专门粘下水管接口的胶水。不能用玻璃胶或万能胶凑合。

地漏：地面那个漏水的篦子。卫生间建议换防臭的；厨房现有的保留，不拆不挪。

地暖：地板为什么会热

你家现在是暖气片，以后改成地板里走热水。热源有两套：现在单位锅炉，以后还能接市政大暖。水太烫不能直接进地暖管，所以中间要「降温再分流」。

混水中心：把锅炉里较烫的水和地暖回水兑在一起，变成 35–45℃ 再送进地板。没有它，管子和地面会烫坏。

分水器：装在餐厅的一排铜阀门。一路进水，再分成客厅、主卧、儿子房、厨房、卫生间几路，每间屋子能单独开关。

地暖盘管：地板里弯来弯去的那根细管，热水从这里流过，砖就热了。这一层里不许有接头，漏了只能砸地。

XPS 挤塑板：铺在管子下面的硬泡沫板。热往上走暖脚，不往楼下邻居天花板里跑。

反射膜：挤塑板上那层亮铝箔，把热再往上弹一层。

卡钉 / 钢丝网：把盘管按间距钉死，倒水泥时管子不会漂起来挤成一堆。

边界保温条：墙根一圈软条。地热了地面会胀，留这圈缝地面才不容易拱、砖才不容易裂。

豆石回填：小圆石子+水泥沙子，把盘管埋住。上面再贴砖。碎石片会扎管子，所以要圆形豆石。

电和网：灯为什么亮、手机为什么能上网

电线（ZC-BV）：铜芯硬线，电从配电箱送到灯和插座。阻燃的意思是万一着火，火不顺着电线管猛窜。照明也用 2.5 平方，线粗一点更安全。

线管：电线必须穿在塑料管里再埋墙，以后还能抽换。红管走强电（照明插座），蓝管走弱电（网线电话）。

WAGO 接头：电线和电线连接用的卡子，按下去就夹紧。不许把线拧一起再缠黑胶布——那是以后发热、打火的隐患。

底盒 / 接线盒：墙上开关插座后面那个方盒子。所有接线只能在盒子里做，不许埋在墙灰里。

锡箔纸：网线和电线交叉时包在网线上，减少干扰，刷视频少卡。

配电箱 + 空开：餐厅墙上的电盒子。总开关 63A；每一路（照明、厨房、空调……）有自己的小开关，跳闸只断一路。

漏保：漏电保护。人碰到电或厨卫受潮漏电时，会瞬间断电，防触电。

弱电箱：电视墙下面放大交换机、接网线的盒子。光猫放柜子上散热，不要塞进这个箱子。

开关插座面板：你平时按的开关、插插头的面板。底盒水电阶段就要埋好，面板可以等墙刷完再扣上。

网线（Cat6A）：有线网络。电视、电脑、儿子书桌走网线比 WiFi 稳。一次埋好用二十年。

水晶头 / 模块：网线两头的接头。一头插设备，一头卡在墙上网口里。必须和线同一级别，否则跑不满速。

光纤：电信/移动入户的那根细玻璃丝。预埋一根从弱电箱到电视墙，以后换宽带不用砸墙。

防水、水泥、砖、缝：地面墙面怎么做出来

防水涂料：厨卫地面和墙根刷的那层「雨衣」。地暖层怕泡，闭水 48 小时自己下楼看天花板，不湿才能贴砖。

附加层：管根、地漏、墙角这些容易裂的地方，先加一层布再刷防水，等于补丁。

水泥：灰色粉末，加水+沙子变硬。用来填管槽、埋地暖、找平。贴大砖不能单靠它，要用瓷砖胶。

沙子：和水泥拌在一起。要用干净河沙，海沙以后墙面会冒白碱、钢筋会锈。

界面剂 / 墙固：刷在老墙或开槽面上的胶水底，让新砂浆、腻子能粘住，减少空鼓脱落。

自流平：倒在地上会自己流平的水泥浆。地还是坑洼时用它找平，再贴砖。

瓷砖：全屋地面和厨卫墙面的面层。地暖上铺砖导热好、也防滑适老。

瓷砖胶：专门粘砖的胶水。地暖会热胀冷缩，用普通水泥砂浆贴大砖，过两年会空鼓掉砖。

留缝条 / 十字卡：贴砖时卡住砖缝宽度（2–3 毫米），缝太小地一热砖会挤裂。

美缝剂（环氧彩砂）：砖缝里打的彩色填缝。比白水泥耐脏、不发黑。厨卫客卧都用这个。

伸缩缝硅酮：墙根那圈地暖预留缝，要用弹性胶，不能用硬美缝填死，否则砖会拱。

墙面、吊顶、门窗、胶

网格布 + 护角条：老墙防裂的「绷带」和阳角的塑料护边，再刮腻子才不容易裂、崩角。

腻子：墙上那层白灰，把墙刮平。必须用耐水的，不然返潮就掉粉起皮。

底漆 + 面漆：底漆封闭腻子、让颜色匀；面漆是你看见的那层颜色。要刷：底 1 遍、面 2 遍。

铝扣板 + 轻钢龙骨：厨卫吊顶。龙骨是天花板上的铁骨架，扣板是扣上去的铝板。油烟好擦，漏了也好揭开检修。

厨房门超薄地轨：玻璃推拉门下面那条很矮的槽，嵌进地砖里，老人不易绊脚。

EPDM 密封条：老窗户四周那圈胶条，换新的能少灌风。窗户本身这期不换。

发泡胶：窗框和墙之间的缝打进去，膨胀后堵住贼风。

玻璃胶（中性硅酮）：收边用的透明/白色胶，阳角、踢脚、烟机洞口防渗。不要买几块钱一支的杂牌。

水浸传感器：厨房水槽下和卫生间各一个小报警器，漏水会叫，免得泡坏地暖层。

记三个就够盯工地

埋进墙和地里的：水管、地暖管、电线、网线、防水——出问题要砸，品牌按后面的表买。
看得见的：砖、漆、开关面板、美缝——可以稍后再定色。
水泥沙子胶水美缝：不是「另算就行」，也要写进合同，否则最容易被换成劣质辅料。
